=== HOST 192.168.1.7 ===
1) Copiar produccion/comun/Vendex-2.0-SNAPSHOT.jar + run.bat a C:\Vendex\  (o instalar MSI)
2) PostgreSQL:
   postgresql.conf: listen_addresses='*'
   pg_hba.conf: host dbVendex app_vendex 192.168.1.0/24 scram-sha-256
   psql: CREATE USER app_vendex WITH PASSWORD 'CAMBIAR';
         GRANT CONNECT ON DATABASE dbVendex TO app_vendex;
         GRANT SELECT,INSERT,UPDATE,DELETE ON ALL TABLES IN SCHEMA public TO app_vendex;
         ALTER DEFAULT PRIVILEGES IN SCHEMA public GRANT SELECT,INSERT,UPDATE,DELETE ON TABLES TO app_vendex;
   Firewall: regla entrada TCP 5432 desde 192.168.1.5
   Reserva DHCP router para 192.168.1.7
3) SQL 1 vez en HOST:
   psql -h localhost -U postgres -d dbVendex -f produccion/comun/sql/fix_multipc_numeracion_20260831.sql
   Verifica: SELECT tipo, establecimiento||'-'||punto_emision, siguiente_numero FROM secuencia_documento;
4) Firma .p12 misma en ambas: C:\Vendex\firma.p12 + C:\Users\TU_USUARIO\.vendex\firma.properties
   ambiente.properties => PRODUCCION
5) Primera ejecucion crea C:\Users\TU_USUARIO\.vendex\db.properties -> dejar host como localhost
   Licencia solo HOST: 449E9-2E789-B71DA-6D23A-20260930 para emugoKABUsDQZhckLohKymLW
6) Ejecutar: run.bat

=== CLIENTE 192.168.1.5 ===
1) Copiar MISMO JAR + run.bat a C:\Vendex\ (o mismo MSI)
2) Copiar misma firma .p12 a C:\Vendex\firma.p12 + firma.properties/ambiente.properties a C:\Users\Cliente\.vendex\
3) Editar C:\Users\Cliente\.vendex\db.properties (plantilla cliente/db.properties.cliente):
   db.url=jdbc:postgresql://192.168.1.7:5432/dbVendex
   db.user=app_vendex
